# Spider-Man for Zed

Dark themes on a midnight-navy base with Spider-Man red, web-blue and suit-gold accents.

| Theme | Description |
|---|---|
| **Spider-Man Soft** | Softened accents and text for long sessions. |
| **Spider-Man Vivid** | The original, brighter palette with classic suit red. |
| **Spider-Man Electro** | Inspired by The Amazing Spider-Man 2: electric blue, plasma violet and ember orange, with suit red keywords. |

## Install

Open the command palette, run `zed: extensions`, search for "Spider-Man", then pick a theme with `theme selector: toggle`.
